Urdu files were supplied by the site owner. Their dataset README credits Rekhta; no independent license for the poems is asserted.
Persian data: Chronological Persian Poetry Dataset, extracted from Ganjoor. Supplied CC BY-SA 4.0 notice retained in PERSIAN-CC-BY-SA-4.0.txt. Adaptation: space separators restored as line breaks, NFC and exact duplicate removal. Dataset adaptations are shared under the same CC BY-SA 4.0 terms.
No translations, audio, biographies or dates were generated. The parallel Roman script is Roman Urdu, not English translation. The separate normalized/stopword-stripped 1.2M-line corpus is excluded to avoid duplicate and damaged literary text.
Source checksums, row counts and shard checksums are in manifest.json.
